# Теоретические сведения

Редактор `vi` — это стандартный текстовый редактор в операционных системах Linux. Он работает в трёх режимах.

**Командный режим** используется для выполнения команд навигации и редактирования текста.

**Режим вставки** используется для ввода текста в файл.

**Режим последней строки** используется для сохранения файла, выхода из редактора и выполнения дополнительных команд.

Для запуска редактора используется команда:


vi <имя_файла>


Основные команды:

- `i` — переход в режим вставки  
- `Esc` — возврат в командный режим  
- `:w` — сохранить файл  
- `:wq` — сохранить и выйти  
- `:q!` — выйти без сохранения  
- `dd` — удалить строку  
- `u` — отменить действие  
- `o` — вставить строку ниже
